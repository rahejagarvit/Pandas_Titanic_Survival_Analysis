# Titanic Survival Analysis

### Project Overview
This project performs an exploratory data analysis (EDA) on the classic Titanic passenger dataset. The goal is to identify key factors that influenced the survival rate of passengers.

### Dataset
The dataset used is the Titanic passenger list, which includes demographic and travel information for 891 passengers. The data was loaded using the Seaborn library and is also available in this repository as `titanic_dataset.csv`.

### Tools and Libraries
* **Language:** Python
* **Libraries:** pandas (for data manipulation), Seaborn (for data loading).
* **Environment:** Jupyter Notebook

### Key Findings
* **Gender:** Female passengers had a significantly higher survival rate (~74%) compared to male passengers (~19%).
* **Socio-Economic Status:** First-class passengers had a much higher chance of survival (~63%) than third-class passengers (~24%).
* **Family Size:** Passengers traveling with family members had a higher survival rate (~51%) than those traveling alone (~30%).

### Conclusion
The analysis confirms that gender, passenger class, and family size were strong predictors of survival on the Titanic.
